# IAI_HW_01

Introduction to Artificial Intelligence - Homework 01

## Project Overview

This project contains implementations for search algorithms required in the first homework of the "Introduction to Artificial Intelligence" course. The environment models a "delivery agent" navigating custom maps of Haifa, inspired by OpenAI’s Frozen Lake.

## Content

- `236501_IAI_SPR26_HW1.ipynb`: Read this notebook first. It describes the assignment, provides demo code, and explains the overall task structure.
- `Algorithms.py`: Implement your solutions in this file. Classes you need to complete:
  - `BFSGAgent` — Breadth-First Search on graphs.
  - `GreedyAgent` — Greedy best-first search (requires custom heuristic).
  - `AStarEpsilonAgent` — A*ε search.
  - `AStarAgent` — Classic A* (uses your A*ε implementation).
- `HaifaEnv.py`: The custom Gym environment ("Haifa"). **Do not edit this file**; changes will be penalized.
- `dryEX1.pdf`: The assignment specification and additional details.

## Instructions

1. Start by reading `236501_IAI_SPR26_HW1.ipynb` and `dryEX1.pdf`.
2. Implement each required agent in `Algorithms.py`.
3. Use the notebook to test your algorithms against the custom environment.
4. Follow comments and docstrings for implementation guidance.
